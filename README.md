# GangaConnect public website

This package preserves the supplied GangaConnect visual design and adds server-backed reports, email notifications, volunteer enrollment, organizer-verified attendance, and downloadable PDF certificates.

## Important distinction

The original HTML was a browser-only prototype using `localStorage`. A browser cannot securely send email to the reporter and your private inbox, keep a central database, or verify attendance. This package adds a Node.js backend for those jobs. It is a deployable project, but it is not live on the public internet until you deploy it to a hosting provider and configure a domain.

## Features

- Pollution report form now requires the reporter's email address.
- Server generates a unique `GC-XXXXXXXX` tracking ID and stores the report in SQLite.
- Confirmation email goes to the reporter; a backup notification goes to `ADMIN_EMAIL`.
- Reports can be tracked from any device using the tracking ID.
- NGO/club/project enrollment captures name and email and creates a `GCE-XXXXXXXX` enrollment ID.
- Organizer can mark attendance through protected admin API.
- A participant can download a PDF certificate only after attendance is verified, using enrollment ID plus matching email.
- Existing GangaConnect colors, layout, cards, hero illustration and sections are retained.

## Run locally

1. Install Node.js 20 or newer.
2. Open this folder in a terminal.
3. Run `npm install`.
4. Copy `.env.example` to `.env`.
5. Fill in SMTP details, `ADMIN_EMAIL`, and a strong `ADMIN_TOKEN`.
6. Run `npm start`.
7. Open `http://localhost:3000`.

For Gmail SMTP, use a Google App Password with 2-Step Verification. Do not use your normal account password. A transactional email service is preferable for a public deployment.

## Organizer/admin API

Send the secret token as an HTTP header: `Authorization: Bearer YOUR_ADMIN_TOKEN`.

- `GET /api/admin/reports` lists reports.
- `PATCH /api/admin/reports/GC-XXXXXXXX` with JSON `{"status":"Under Verification"}` updates report status.
- `GET /api/admin/enrollments` lists enrollments.
- `PATCH /api/admin/enrollments/GCE-XXXXXXXX/attendance` with JSON `{"attended":true}` verifies attendance and emails the participant.

Example using curl:

```bash
curl -H "Authorization: Bearer YOUR_ADMIN_TOKEN" https://YOUR-DOMAIN/api/admin/enrollments
curl -X PATCH -H "Authorization: Bearer YOUR_ADMIN_TOKEN" -H "Content-Type: application/json" -d '{"attended":true}' https://YOUR-DOMAIN/api/admin/enrollments/GCE-XXXXXXXX/attendance
```

## Public deployment

Deploy this folder to a Node.js host that supports persistent disk storage (SQLite database file), set the environment variables from `.env.example` in the host dashboard, and attach your domain. Do not commit `.env`, SMTP credentials, or `ADMIN_TOKEN` to GitHub. Use HTTPS. Configure persistent storage for `gangaconnect.db`; otherwise some hosts erase local files during redeploys.

## Before real-world launch

- Replace sample NGO/club/project names, dates, images and descriptions with verified information. The current cards are demonstration content.
- Add an organizer/admin dashboard with login and role-based access before giving attendance controls to multiple organizations.
- Add privacy policy, terms, consent text, retention rules, CAPTCHA/anti-spam and image moderation.
- Configure email delivery and test spam-folder placement.
- Use a managed database/object storage if report volume or image uploads grow.
- The certificate is a participation certificate generated by this website. It is not an official government certificate or proof of government authorization.
